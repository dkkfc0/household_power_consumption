# household_power_consumption
Сначала безопасно проверить, существует ли файл, и прочитать только первые 50 строк без изменения исходника. На этом фрагменте проверяем структуру заголовка, разделитель ; и встречаемость потенциальных маркеров пропусков. Для исходного UCI-набора разделителем действительно является точка с запятой, а официально пропущенное измерение описывается как пустое поле между двумя соседними ;; в наборе около 1,25% строк содержат пропущенные измерения. 

После инспекции загружаем весь файл в DataFrame, явно задавая sep=';', na_values=['?', 'NA', ''], decimal='.', encoding='latin1' и low_memory=False. Затем создаём единый временной столбец DateTime, сохраняя исходные Date и Time, и выводим head, shape, dtypes и число пропусков. Никакие строки при этом не удаляются, пропуски не заполняются, агрегация не выполняется, а исходный файл открывается только на чтение.
